# M01 — separate discovery and necessity artifacts

Implemented on `mapping/m00-m05`, uncommitted for author review, based on
`3520f7912f40c456a120b28fdfc48d855a28b28f`. Author authorization in the implementation
request supersedes the design record's historical proposal-only status. M01 retains
its registered two-day ceiling, `ergo-sandbox` package, `mapping_artifacts` target,
and all three original test names. No later unit is implemented.

`map::discovery::DiscoveryMap` serializes as `discovery-map:v2`. Its edge states
are hint, observed-match, rejected-match and unresolved. It retains raw RecordedBox
documents, queries, observed code, reference predicates, proposed roles/targets,
snapshot premises, caps and unresolved reasons. Nomination requires an unambiguous
observation ID and returns only a candidate identifier. Neither nomination nor map
import resolves independent evidence. Compile-fail examples enforce the absence
of conversions into RequiredRelations and the frozen legacy DrainRequest.

`map::relations::RequiredRelations` serializes separately as
`required-relations:v1`. M01 exposes unresolved proposals only. Deserialization
rejects established-under-premises/refuted statuses and unknown versions/fields;
there is no proof-producing or action-checking API. Unchecked derivation material,
anchors, authenticated-byte observations and dependencies remain inspectable.
Claim identity binds the subject, relation target and entire premise bundle. The
single guard is stored in P, with typed literals and explicit context/SELF scope.
Canonical JSON digesting ignores object-key order but preserves arrays, missing
premises, origin labels and raw documents. Imports reject stale premise/claim
digests. Recomputing these public digests creates only another unresolved proposal,
never proof authority. No semantic normalization, exact-tree checking, canonical
reference resolution or witness assessment is claimed by M01.

Raw provenance labels are retained assertions, not independent state validation.
Missing registers, explicitly empty registers and explorer register metadata
survive round-trip distinctly. No legacy defaulting or map-to-canonical conversion
is used. The gate remeasures the unchanged M00 legacy results, including all 32
pinned case snapshots and the public map recordings; registered manifest, answer
and case hashes are checked. New schema examples and `m01-mapping-results.json`
are separate files, not new members of the M00 corpus. Result diagnostics print
their paths and SHA-256 hashes; result revision fields come from the pinned inventory.

No design amendment, threshold reduction or stop record was needed. An initial
new-test bug indexed `legacyMapJson` inside an already canonical map; the assertion
was corrected to serialize that map and compare its bytes to the existing pinned
string. No expected fact or snapshot changed. M02 extraction, M03 proof checking,
M04 action checking and M05 context-code resolution remain unimplemented because
this request authorizes M01 only.
